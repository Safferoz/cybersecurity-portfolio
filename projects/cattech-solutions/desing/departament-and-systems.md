# CatTech Solutions - Departments and Systems

## Company Overview

CatTech Solutions is a fictional technology company focused on software development and technical services.

The company has approximately 45 employees.

## Departments

| Department | Estimated Employees | Description |
|---|---:|---|
| Development | 22 | Software development and project delivery |
| Technical Support | 8 | User and service support |
| IT | 5 | Infrastructure, systems and security administration |
| Finance | 4 | Financial operations and sensitive documentation |
| Human Resources | 3 | Employee management and HR documentation |
| Management | 3 | Business oversight and decision-making |

## Department Needs

### Development
- Domain user accounts
- Workstations
- Access to internal resources

### Technical Support
- Domain user accounts
- Workstations
- Access to support-related tools
- Some elevated privileges for support activities

### IT
- Administrative accounts
- Access to servers and network devices
- Infrastructure management privileges

### Finance
- Domain user accounts
- Workstations
- Access to sensitive financial resources

### Human Resources
- Domain user accounts
- Workstations
- Access to employee-related sensitive resources

### Management
- Domain user accounts
- Workstations
- Broad access to business resources

This lab does not represent every employee with a dedicated machine.
Instead, the environment uses a small number of representative systems while simulating a larger enterprise structure through Active Directory users, groups and permissions.
